  1. 💡 **힌트**: 게임 속 힌트와 같은 문구
  2. ✅ **모순 정답**: 거짓 진술과 그걸 깨는 근거
  3. 🎯 **범인 & 결말**
- 스포일러가 싫다면 힌트만 보고 다시 도전해 보세요!
